Getting connected

  1. Use Chrome on Android (or Chrome/Edge on a laptop). Safari and Firefox don't support Web Bluetooth.
  2. The page must be served over https (for example GitHub Pages or your own site). Phones also need Bluetooth and Location switched on.
  3. Close the adidas app first, or turn off Bluetooth on the device running it. The treadmill accepts one connection at a time.
  4. Switch the treadmill on, clip in the safety key, tap Connect treadmill and pick it from the list.

The app talks to the treadmill using the standard Bluetooth fitness-machine protocol (FTMS), the same one Kinomap uses. If the treadmill reports data but ignores speed changes, it isn't accepting remote control, and the app will tell you.

Safety: the treadmill's own Stop button and safety key always work. Keep the key clipped on.

Strava Not connected

Open this page through localhost or your https site to connect Strava. Strava can't send you back to a file opened by double-clicking.

  1. Create a free API application at strava.com/settings/api. Any name and website will do. Set Authorization Callback Domain to localhost.
  2. Paste the app's Client ID and Client Secret below. They're kept in this browser only.
  3. Press Connect to Strava and approve access. You'll come straight back here.
